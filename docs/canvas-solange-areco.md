# CANVAS --- Desarrollo e Implementación de Sitio Web Institucional

**Proyecto:** Sitio Web Institucional del ISFT N.º 199\
**Responsable:** Solange Areco\
**Carrera:** Tecnicatura Superior en Ciencia de Datos e Inteligencia
Artificial\
**Contexto:** Proyecto Integrador

## 1. Propuesta de valor

Desarrollar sitios web institucionales y comerciales funcionales,
accesibles y adaptables a distintos dispositivos, que permitan
centralizar información, facilitar la comunicación con los usuarios y
mejorar la presencia digital de organizaciones.

La experiencia adquirida en el desarrollo del sitio institucional del
ISFT N.º 199 constituye la base para ofrecer futuros servicios de
desarrollo web.

## 2. Segmentos de clientes

-   Instituciones educativas.
-   Pequeños comercios.
-   Emprendedores.
-   Profesionales independientes.
-   Organizaciones que necesiten un sitio web.

## 3. Problema o necesidad

Organizaciones y pequeños negocios pueden necesitar un sitio web propio
para presentar sus servicios, comunicar información, facilitar el
contacto con sus usuarios y disponer de una plataforma digital
centralizada.

## 4. Solución

Desarrollar sitios web adaptados a las necesidades de cada organización,
con funcionalidades como:

-   Presentación institucional o comercial.
-   Información organizada y accesible.
-   Diseño adaptable a celulares y computadoras.
-   Formularios de contacto.
-   Integración de herramientas de comunicación.
-   Administración y actualización de contenidos.
-   Publicación en Internet mediante dominio y hosting.

## 5. Canales

-   Sitio web propio o portfolio de proyectos.
-   Contacto directo con potenciales clientes.
-   Recomendaciones.
-   Redes sociales como canales de difusión, cuando el cliente ya
    disponga de ellas.
-   Plataformas de servicios profesionales.

En el proyecto institucional, las redes sociales ya existían previamente
y no formaron parte de mi desarrollo.

## 11. Caminos de ingreso y elección

A partir de los conocimientos y la experiencia práctica adquiridos en
el desarrollo del sitio institucional del ISFT N.º 199, identifico dos
caminos posibles para generar ingresos, y elijo uno de ellos.

### Camino 1 — Relación laboral

Podría desempeñarme en un puesto de **desarrolladora web junior** o
**programadora junior**, aplicando lo aprendido durante el Proyecto
Integrador.

Tareas que podría realizar:

-   Desarrollo y mantenimiento de páginas web y funcionalidades
    backend sencillas.
-   Maquetación y adaptación de interfaces (HTML, CSS, JavaScript).
-   Integración de formularios, APIs y herramientas de comunicación.
-   Soporte técnico y corrección de errores.
-   Trabajo en equipo con control de versiones (Git y GitHub).

Tipo de empresa donde podría trabajar: estudios de desarrollo web,
agencias digitales, o pequeñas y medianas empresas que necesiten
incorporar o mantener su presencia web propia.
