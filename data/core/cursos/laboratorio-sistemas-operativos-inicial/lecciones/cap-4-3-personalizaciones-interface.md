### Personalizar la interface

Un sistema bien personalizado **reduce errores** y hace más cómoda la operatoria. La interface con el usuario debe ser **clara**: elementos ordenados, contrastes adecuados y accesos rápidos a lo que más usamos.

### Principios de una buena interface

1. **Claridad:** saber qué hace cada elemento de la pantalla.
2. **Orden:** iconos y ventanas organizados sin desorden.
3. **Accesibilidad:** textos legibles y atajos para las tareas frecuentes.
4. **Personalización:** adaptar el entorno al modo de trabajo de cada usuario.

### Personalizaciones en XFCE

**Cambiar el fondo de pantalla:**

```text
Menú -> Configuración -> Escritorio -> pestaña Fondo
```

**Cambiar el tema y los iconos:**

```text
Menú -> Configuración -> Apariencia -> pestañas Estilo e Iconos
```

**Agregar lanzadores al panel:**

```text
Clic derecho sobre el panel -> Panel -> Preferencias del panel -> Elementos -> Agregar -> Lanzador de aplicaciones
```

**Organizar iconos del escritorio:**

Con clic derecho sobre el escritorio, la opción *Organizar iconos* ordena los elementos automáticamente.

### Atajos de teclado útiles

| Atajo | Acción |
| :--- | :--- |
| `Alt + Tab` | Cambiar entre ventanas |
| `Super` | Abrir el menú de aplicaciones |
| `Ctrl + Alt + T` | Abrir la terminal |
| `Alt + F4` | Cerrar la ventana activa |

Los atajos se configuran en *Configuración → Teclado → pestaña Atajos*.

### Personalización de la terminal

La terminal también se personaliza: perfil, colores, tipografía y transparencia en *Editar → Preferencias* dentro de la terminal XFCE.

### Micro-desafío práctico

> Personalizá tu escritorio: cambiá el fondo de pantalla, elegí un tema de color de alto contraste, agregá lanzadores al panel para la terminal y el administrador de archivos, y configurá un atajo para abrir la terminal. Anotá qué cambios hiciste y por qué.

### Resumen

- Una interface clara y ordenada reduce errores de operatoria.
- XFCE permite personalizar fondo, temas, iconos y panel.
- Los atajos de teclado aceleran las tareas frecuentes.
- La personalización se adapta al modo de trabajo del usuario.
