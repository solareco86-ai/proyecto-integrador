### ¿Qué es el panel de control?

El **panel de control** es el conjunto de herramientas gráficas que permite configurar el sistema sin usar la terminal. En XFCE se agrupan en el menú **Configuración** y en **Configuración del sistema**.

Su utilidad principal es la **monitorización y configuración básica**: fecha y hora, pantalla, teclado, sonido, energía y usuarios.

### Herramientas del panel en XFCE

| Herramienta | ¿Qué permite configurar? |
| :--- | :--- |
| Configuración del sistema | Acceso a todas las preferencias |
| Pantalla | Resolución, orientación y monitores |
| Administrador de energía | Ahorro de energía y apagado de pantalla |
| Apariencia | Temas, iconos y tipografías |
| Teclado | Diseño del teclado y atajos |
| Sesiones e inicio | Programas que arrancan con la sesión |
| Administrador de archivos | Vista de carpetas y archivos |

### Monitorización visual en XFCE

El panel inferior de XFCE puede mostrar **indicadores** en tiempo real:

- **Monitor del sistema:** uso de CPU y memoria.
- **Monitor de red:** tráfico de las interfaces.
- **Reloj:** fecha y hora.

Para agregarlos: clic derecho sobre el panel → *Agregar nuevos elementos* → elegir el monitor.

### Configuración básica con ejemplos

**Cambiar la resolución de pantalla:**

```text
Menú -> Configuración -> Pantalla -> elegir resolución -> Aplicar
```

**Configurar el apagado automático de pantalla:**

```text
Menú -> Configuración -> Administrador de energía -> Pestaña Pantalla
```

**Cambiar el tema visual:**

```text
Menú -> Configuración -> Apariencia -> pestaña Estilo
```

### Micro-desafío práctico

> Abrí *Configuración del sistema* en XFCE. Identificá y listá en tu cuaderno las herramientas disponibles. Agregá el *Monitor del sistema* al panel inferior y observá cómo varía el uso de CPU al abrir el administrador de archivos.

### Resumen

- El panel de control centraliza la configuración gráfica del sistema.
- Permite ajustar pantalla, energía, apariencia, teclado y sesiones.
- El panel de XFCE admite indicadores de monitorización en vivo.
- Configurar bien estos aspectos reduce errores de uso.
