### El escritorio XFCE

**XFCE** es el entorno de escritorio que usamos en el laboratorio. Es **liviano, rápido y personalizable**, ideal para equipos con recursos limitados y para aprender los conceptos de interface del sistema operativo.

### Componentes del escritorio

| Componente | Función |
| :--- | :--- |
| Escritorio | Fondo, iconos y área de trabajo |
| Panel (barra inferior) | Lanzadores, reloj, indicadores |
| Gestor de ventanas | Barras de título, bordes, mover y redimensionar |
| Menú de aplicaciones | Acceso a los programas instalados |
| Gestor de archivos | Navegación por carpetas y archivos |

### Las visualizaciones que brinda el sistema

El sistema operativo ofrece diferentes **visualizaciones** para trabajar:

- **Escritorio gráfico:** ventanas, iconos y menús (XFCE).
- **Terminal:** línea de comandos para ejecutar programas y administrar.
- **Administrador de archivos:** carpetas y archivos de forma gráfica.
- **Monitor del sistema:** uso de CPU, memoria y procesos.

### Uso del panel

El panel de XFCE es el centro de control visual:

- **Lanzadores de aplicaciones:** atajos para programas frecuentes.
- **Reloj y calendario:** clic sobre la hora muestra el calendario.
- **Áreas de notificación:** iconos de red, sonido y batería.
- **Cambio de escritorios:** varios espacios de trabajo virtuales.

### Micro-desafío práctico

> Explorá el escritorio XFCE. Identificá y anotá: qué elementos tiene el panel, cómo se abre el menú de aplicaciones, cómo se cambia entre escritorios virtuales y qué visualizaciones (ventanas, terminal, administrador de archivos) podés tener abiertas a la vez.

### Resumen

- XFCE es un escritorio liviano, rápido y personalizable.
- Sus componentes son el escritorio, el panel, el gestor de ventanas y el menú.
- El sistema ofrece visualizaciones gráficas y de terminal.
- El panel concentra lanzadores, reloj e indicadores.
