### ¿Qué es programar?

La **programación de computadoras** es la ciencia que permite a una persona darle instrucciones a una computadora para que resuelva tareas de manera rápida. Un **programa** es una secuencia de instrucciones que indican las acciones o tareas que han de ejecutarse para dar solución a un problema determinado.

Programar es indispensable en cualquier área de la ingeniería: muchos problemas que tardan horas en resolverse de forma manual, una computadora bien programada los resuelve en segundos. Lo importante es que la computadora resuelve el problema **de acuerdo a cómo se le haya programado**.

### Pasos para desarrollar un programa

Para llegar a una secuencia de instrucciones que resuelva un problema, es necesario recorrer varias etapas:

| Etapa | Nombre | Qué se hace |
| :--- | :--- | :--- |
| 1 | Análisis | Entender claramente el problema: qué es lo que se quiere resolver. |
| 2 | Solución general | Escribir la serie de pasos necesarios usando un diagrama de flujo (símbolos) o un algoritmo (lenguaje común). |
| 3 | Prueba de escritorio | Chequear el algoritmo paso a paso para asegurarse de que resuelve verdaderamente el problema. |
| 4 | Implementación específica | Traducir el algoritmo a un lenguaje de programación (codificar). |
| 5 | Implementar | Ejecutar el programa en la computadora, revisar los datos arrojados y corregir lo necesario. |
| 6 | Uso | Instalar el programa de manera definitiva para que lo utilice el usuario. |

### Ejemplo de un problema simple

> **Consigna:** sumar dos números y mostrar el resultado.

En la etapa de solución general, sin escribir código, la secuencia sería:

1. Pedir el primer número.
2. Pedir el segundo número.
3. Sumar ambos números.
4. Mostrar el resultado.

Más adelante, en las etapas 4 y 5, esa secuencia se traduce a un lenguaje de programación:

```python
a = int(input("Primer número: "))
b = int(input("Segundo número: "))
print("La suma es:", a + b)
```

### Resumen

- Programar es darle instrucciones a una computadora para resolver un problema.
- Un programa es una secuencia de instrucciones.
- El desarrollo atraviesa 6 etapas: análisis, solución general, prueba, codificación, implementación y uso.
- La prueba de escritorio evita codificar soluciones incorrectas.
