# 1.3 Scope MVP: qué entra, qué no (para esta iteración)

## Objetivo

Definir qué features son **esenciales** (MVP) vs. qué queda para iteraciones futuras.

## Contenidos

### 1. MVP vs. Full Product

```yaml
# Proyecto Energético

MVP (Sprint 1-2, 16 semanas):
  - Lectura de sensores MQTT
  - Dashboard básico (consumo últimas 24h)
  - Almacenamiento en BD
  - API REST para datos

No MVP (futuro):
  - Predicción ML (Nice to have)
  - Bot conversacional (iteración 2)
  - Análisis de cargas (Fase 2)

# Proyecto Institucional

MVP:
  - Listado de carreras + descripción
  - Información de requisitos de ingreso
  - Búsqueda simple
  - Contacto (formulario)

No MVP:
  - Bot inteligente (Fase 2)
  - Recomendador ML (Fase 2)
  - Análisis de trayectorias (Fase 3)
```

### 2. Criterios para MVP

- ¿Es obligatorio para resolver el problema principal?
- ¿Es viable en 16 semanas con el equipo disponible?
- ¿Tiene ROI claro?

### 3. Roadmap de fases

```
Semanas 1-8:  MVP (definición, planificación)
Semanas 9-16: MVP Implementado + 1 feature extra
Fase 2+:      Mejoras, ML, Bots, Análisis avanzado
```
