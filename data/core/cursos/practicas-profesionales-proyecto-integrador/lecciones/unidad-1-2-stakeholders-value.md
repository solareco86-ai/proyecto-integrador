# 1.2 Identificar stakeholders y value proposition

## Objetivo

Mapear quiénes son los actores clave y articularles qué valor reciben.

## Contenidos

### 1. Stakeholders

```yaml
# Proyecto Energético (energy-ml)

Primarios (usan directamente):
  - Gerente de infraestructura: "Quiero saber consumo en tiempo real"
  - Técnico de mantenimiento: "Quiero detectar cargas anómalas"
  - CFO: "Quiero optimizar costos energéticos"

Secundarios (afectados):
  - Director ISFT: "Quiero reducir gastos operativos"
  - Estudiantes: "Quiero aprender del sistema"

Terciarios (toman decisiones):
  - Proveedor energético: "Quiero datos para auditoría"
  - Regulador (DGCyE): "Quiero garantizar eficiencia"
```

```yaml
# Proyecto Institucional (web)

Primarios:
  - Alumno ingresante: "Quiero saber qué carrera elegir"
  - Alumno activo: "Quiero ver plan de estudio, calificaciones"
  - Secretaría: "Quiero reducir consultas manuales"

Secundarios:
  - Docente: "Quiero ver engagement de alumnos"
  - Director: "Quiero reducir deserción"

Terciarios:
  - Empleador: "Quiero graduados bien preparados"
  - DGCyE: "Quiero calidad de formación"
```

### 2. Value Proposition (por stakeholder)

¿Qué recibe cada uno?

```
Para el Gerente de Infraestructura:
  "Monitoreo en tiempo real del consumo energético, 
   alertas automáticas de anomalías, histórico para análisis"

Para el Alumno Ingresante:
  "Orientación clara sobre carreras, plan de estudio, 
   requisitos de ingreso, toda la info en un lugar"

Para la Secretaría:
  "Bot responde 80% de consultas automáticamente, 
   menos carga administrativa"
```

### 3. Jobs to be Done (JTBD)

¿Qué tarea específica hace el usuario?

```
Energía:
  - "Quiero identificar por qué subieron los costos en octubre"
  - "Quiero saber si el aire acondicionado está mal configurado"

Académico:
  - "Quiero elegir carrera sin confundirme"
  - "Quiero ver mis calificaciones y avance"
```

## Actividad Práctica

1. Listar 5-10 stakeholders (primarios, secundarios, terciarios)
2. Para cada uno, escribir su value proposition (1-2 líneas)
3. Identificar 2-3 "jobs" específicos

## Palabras clave

Stakeholders, value proposition, JTBD (Jobs To Be Done), usuarios, actores
